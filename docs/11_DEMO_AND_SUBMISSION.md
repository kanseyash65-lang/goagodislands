## 3. Recording Plan

**Tools:** OBS or a built-in screen recorder, 1080p, 30 fps, mic audio on (judges hear you speaking), keep the Wispr Flow indicator in frame.

**Structure (recommended 10–20 min edited, or full unedited time-lapse + highlights):**

| Segment | Content |
|---------|---------|
| 0:00 | 15-sec intro: "A game about speaking reality into existence, built by speaking." Show Wispr Flow + the docs folder. |
| Build | Show each milestone kickoff by voice, Claude working, tests/build passing, quick browser checks. Speed-ramp the long waits (label "time-lapse"). Don't cut out the voice prompts. |
| Milestone reveals | After M1, M3, M5, M6 show the game doing something cool (≈ 20 s each). |
| Finale | Run the 2-minute demo script (section 4) **live by voice** in the finished game. |
| Outro | Show `dist/index.html` double-clicked offline, 0 network requests, credits screen. |

Do not hide failures: a failed command → "Improv Engine handled it" is a *feature*. Showing a debug-by-voice moment demonstrates the voice workflow.

## 4. The 2-Minute Live Demo Script (voice, in the game)

Rehearse this 3×. Every line has a guaranteed payoff.

| t | Say | Expected payoff |
|---|-----|-----------------|
| 0:00 | (calm village, music) "This is an average Tuesday." | Title card fades, villagers working |
| 0:10 | "Turn the sun green." | World tints green, villager: *"I've never trusted green suns."* |

## 9. Risk Register

| Risk | Mitigation |
|------|-----------|
| Wispr text arrives slowly/oddly | Debounced auto-submit + Enter; "Reality heard" ribbon; keyboard fallback |
| Parser misses a phrase live | Improv Engine; suggestion chips; Demo Mode |
| WebGL/perf trouble on judge laptop | Auto quality fallback; particle caps; tested at 1,000 entities |
| Audio blocked | Unlock on first gesture; mute toggle; visible hint |
| Build too big/slow | `verify` size gate; tree-shaken Three imports (named imports only) |
| Scope creep | Priority order in `10` §9 — cut from the bottom |
| Recording problems | Test recording before M0; keep a local backup; record in segments |
