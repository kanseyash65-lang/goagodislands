## 0. What We Are Building (one paragraph)

A **single-file, offline, browser game** (`dist/index.html`) built with **Vite + TypeScript + Three.js + CSS**.
It *looks* 2D (orthographic top-down camera, stylized procedural sprites) and is rendered by Three.js for speed and effects (instancing, shaders, lighting).
The player is an invisible god who changes a living village **by speaking** (Wispr Flow types the transcript into the game's always-focused command bar).
**Every asset (art, sound, music, fonts, UI icons) is generated by code at runtime. Zero external files. Zero network calls.**

## 2. Hard Technical Constraints (non-negotiable)

| # | Constraint |
|---|-----------|
| C1 | Output is **ONE `index.html`** (JS + CSS inlined) via `vite-plugin-singlefile`. Opens by double-click (`file://`) and works offline. |
| C2 | Stack: **Vite + TypeScript (strict) + Three.js (npm, bundled) + plain CSS**. No React, no backend, no CDN. |
| C3 | **No external assets.** No PNG/JPG/MP3/WAV/font files, no `fetch` of anything, no Google Fonts. |
| C4 | All art = **procedural**: drawn with Canvas2D into `CanvasTexture` atlases at boot, or Three.js geometry/shaders. |
| C5 | All audio = **WebAudio synthesis** (oscillators, noise, filters, envelopes). |
| C6 | Fonts = **system font stack** + a procedurally drawn pixel/bitmap title logo. |
| C7 | Voice = Wispr Flow dictates into a **focused `<input>`**. Optional bonus: Web Speech API button (clearly optional; game must never depend on it). |
| C8 | **60 FPS with 1,000+ entities** (instanced rendering). |
| C9 | Final `index.html` ideally **< 1.5 MB**. |
| C10 | Never crash on any text input. **Every sentence does *something*** (see Improv Engine in `05`). |
